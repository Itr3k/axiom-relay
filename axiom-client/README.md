# `axiom-relay` package (retired)

This package is the archived client for a retired Axiom x402 and crypto-routing
service. Do not use it for a new integration and do not treat its embedded
endpoint defaults or API types as current product truth.

The current Axiom Relay product and its live machine discovery are published at
[AxiomRelay.io](https://axiomrelay.io). The package source remains available only
for compatibility archaeology and is marked private in this repository to block
accidental republication.
